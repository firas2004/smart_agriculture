Logique de decision

Fonctionnement du systeme

Un algorithme multicritere s'execute toutes les 30 secondes pour decider si l'irrigation est necessaire.

🤖 Mode Automatique

1

Lecture capteur sol

analogRead(A0) toutes les 30s. Valeur 0-1023 envoyee a ThingSpeak field1.

2

Sol humide ? Fin.

Si valeur <= 600 : sol suffisamment humide. Pompe OFF. Aucune action.

3

Verification meteo

GET ThingSpeak field3. rainExpected=1 : pluie prevue, pas d'irrigation, LED pluie ON.

4

Verification heure NTP

Creneau matin (5h-9h) ou soir (18h-20h) : Pompe ON. Sinon : attente, LED pluie ON.

5

Irrigation declenchee

digitalWrite D2 HIGH, relais ON, pompe ON. LED pompe D1 allumee. Log Blynk V10.

📱 Mode Manuel Blynk

M

Appui bouton Blynk V0

Utilisateur appuie dans l'app. BLYNK_WRITE(V0) appele avec valeur = 1.

⚡

Override active

manualOverride=true, timer demarre. Pompe ON et LED pompe ON immediatement.

⌛

Duree : 10 secondes

Apres 10s (manualDuration=10000ms), le systeme coupe automatiquement la pompe.

✓

Retour mode auto

manualOverride=false. Cycle automatique reprend au prochain intervalle.

🎯 Arbre de decision

Sol humide (<=600) → OK Rien
Sol sec (>600) → Verif meteo
  Pluie prevue → Pause
  Pas de pluie → Verif heure
    Bon creneau → 💧 Pompe ON
    Mauvais creneau → ⌛ Attente
Architecture de communication

Les 7 axes de communication

Chaque flux de donnees entre composants est un axe de communication — de l'analogique local au cloud mondial.

🌿
Axe 1 — Capteur sol → ESP8266
Analogique A0

Mesure humidite toutes les 30s. Valeur 0-1023 lue avec analogRead(). Seuil sec : > 600.

💧
Axe 2 — ESP8266 → Pompe (Relais)
Digital OUT D2 → Relais → Pompe

digitalWrite HIGH/LOW sur D2 commande le relais. Alimentation pompe separee 4.5V.

💡
Axe 3 — ESP8266 → LEDs
Digital OUT D1 / D6 / D7

Feedback visuel local : LED pompe (D1), LED pluie/attente (D6), LED etat (D7).

☁️
Axe 4 — ESP8266 ⇄ ThingSpeak
HTTP GET api.thingspeak.com

Envoi humidite vers field1. Lecture prevision pluie depuis field3. Via ESP8266HTTPClient.

📱
Axe 5 — ESP8266 ⇄ Blynk App
Virtual Pin V0 / V10

Envoi logs vers V10 en temps reel. Reception commande manuelle depuis V0 (bouton app).

🕐
Axe 6 — ESP8266 ← NTP Servers
UDP pool.ntp.org / time.nist.gov

Synchronisation heure exacte au demarrage. Heure verifiee toutes les 30s pour le creneau.

🌦️
Axe 7 — MATLAB ⇄ OpenWeatherMap + ThingSpeak
HTTPS api.openweathermap.org

Script MATLAB : 72h de previsions (24 blocs x 3h), detecte pluie >= 0.1mm, envoie flag (0/1) a ThingSpeak field3.

C++ / Arduino
// Configuration Blynk
#define BLYNK_TEMPLATE_ID   "TMPL22621bfPf"
#define BLYNK_TEMPLATE_NAME "smartagri"
#include <ESP8266WiFi.h>
#include <BlynkSimpleEsp8266.h>
#include <ESP8266HTTPClient.h>
#include <time.h>

// Broches
const int soilPin      = A0; // Capteur humidite
const int pumpRelayPin = D2; // Relais pompe
const int pumpLedPin   = D1; // LED pompe
const int rainLedPin   = D6; // LED pluie
int dryThreshold = 600;

void loop() {
  Blynk.run();
  if (!manualOverride && millis()-lastCheck >= 30000) {
    int soilValue = analogRead(soilPin);
    sendSoilToThingSpeak(soilValue);
    int hour = getHour();
    if (soilValue > dryThreshold) {
      int rain = getRainForecast();
      if (rain == 1) {
        logToTerminal("Pluie attendue. Pas d'irrigation.");
      } else if ((hour >= 5 && hour <= 9) ||
                 (hour >= 18 && hour <= 20)) {
        digitalWrite(pumpRelayPin, HIGH); // POMPE ON
      } else {
        logToTerminal("Mauvais creneau. Attente.");
      }
    }
  }
}

// Callback Blynk - Controle manuel
BLYNK_WRITE(V0) {
  if (param.asInt() == 1) {
    digitalWrite(pumpRelayPin, HIGH);
    manualOverride = true;
    manualStartTime = millis();
  }
}
sendSoilToThingSpeak()
void sendSoilToThingSpeak(int val) {
  String url = "http://api.thingspeak.com/update"
             + "?api_key=" + writeAPIKey
             + "&field1=" + String(val);
  http.begin(client, url);
  http.GET();  http.end();
}
getRainForecast()
int getRainForecast() {
  String url = server
    + "/channels/" + channelID
    + "/fields/" + fieldNumber
    + "/last.txt?api_key=" + readAPIKey;
  http.begin(client, url);
  if (http.GET() == 200)
    return http.getString().toInt();
  return 0;
}
